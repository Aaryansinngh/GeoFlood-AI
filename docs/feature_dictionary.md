# Feature Dictionary

## 1. Overview & Data Schema

This document details every feature generated by the GeoFlood AI pipeline, stored in `data/processed/features.parquet` and `data/sample/features_sample.parquet`.

All spatial layers are aligned to a unified 2D grid in **EPSG:4326 (WGS 84)** with approximately **~250m cell resolution** across the study bounding box: `[92.80°E, 26.30°N, 94.20°E, 27.20°N]`.

## 3. Strict Leakage Controls

To adhere to rigorous academic ML principles, the following controls are enforced:
1. **Zero Label-Derived Input Features:** No feature contains information derived from the current or future flood extent mask. Distance-to-flooded-area, flood duration, or downstream flood indicators are strictly forbidden as input features.
2. **Permanent Water Masking:** Permanent water cells (`is_perm_water == 1`) are flagged and excluded from binary classification training so the models do not simply learn to classify water bodies.
3. **No Target Leakage in Rainfall:** Pre-event rainfall (`rain_3d`, `rain_7d`) is strictly calculated prior to the event onset date ($t < t_{\text{start}}$).
4. **Missing Values Integrity:** Cells with cloud gaps or unobserved data are recorded as `NaN` (unavailable) and never imputed to `0.0` ("safe").
